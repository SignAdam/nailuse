# Nailuse

Studio interactif de personnalisation des ongles en 3D.

## Lancer en local

Servez le dossier `dist` avec un serveur HTTP :

```sh
python3 -m http.server 8000 --directory dist
```

Puis ouvrez http://localhost:8000.

Modifiez les fichiers HTML, CSS et JavaScript dans `dist/`. Les ressources 3D, images, bibliothèques et leurs licences se trouvent dans `dist/assets/`.
