# Nailuse

Studio interactif de personnalisation des ongles en 3D.

## Lancer en local

Servez le dossier `dist` avec un serveur HTTP, par exemple :

```sh
python3 -m http.server 8000 --directory dist
```

Puis ouvrez http://localhost:8000.

Les fichiers HTML, CSS et JavaScript sont directement modifiables dans `dist/`. Les modèles, images et bibliothèques sont dans `dist/assets/` ; leurs licences sont incluses.
